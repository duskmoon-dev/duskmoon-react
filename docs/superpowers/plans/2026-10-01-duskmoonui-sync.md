# DuskMoonUI synchronization plan — 2026-10-01

The initial development pins for both packages were `1.19.9`; npm `latest` for both was `1.20.0`. Core registry metadata points to `duskmoon-dev/duskmoonui`, `packages/core`; the CSS-art package points to the same repository, `packages/css-art`. Evidence sources are the published tarballs, registry metadata, and versioned upstream source/docs. Dependency and integration edits are now implemented in source; runtime verification remains paused. This plan records the selected contracts and boundaries.

Verification is **PAUSED by the user**. No tests, builds, typechecks, browser checks, or parity checks have run. The plan supports the authorized implementation sync; sync completion remains pending. Do not change this project's release version, commit, or publish as part of the sync.

## Agreed React wrapper design contracts (immediate implementation scope)

- **OtpInput:** one native input owns the ref and native `onChange`; `length` is 1–8 and defaults to 6; empty decorative `aria-hidden` spans mark the slots while native input text overlays them; forward native `required`, `minLength`, `maxLength`, `pattern`, and other appropriate input props. Do not add per-cell focus movement.
- **Swap:** a native checkbox with `checked`, `defaultChecked`, and `onChange` drives state; provide decorative `on` and `off` slots and a rotate variant. Preserve existing `Switch` and `Toggle` APIs.
- **Fab:** compose the existing `Button` with FAB geometry and native speed-dial actions. Preserve `FloatButton`.
- **Megamenu:** semantic navigation with native popover behavior, unique IDs, and anchors; do not use ARIA menu roles. Preserve `Menu` and `Dropdown`.
- **ConsolePage:** responsive shell with expanded, compact, and hidden sidebar states plus a native mobile menu. Preserve `Layout` and `DmLayout`.
